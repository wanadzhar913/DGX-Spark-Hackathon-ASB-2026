# Screenshots

Place your dashboard screenshots in this folder using these exact file names so
they render in the main project `README.md`:

| File name            | What to capture                                             |
|----------------------|-------------------------------------------------------------|
| `dashboard-full.png` | The whole dashboard (video wall + events panel + snapshots) |
| `video-wall.png`     | Just the video wall grid of live feeds                      |
| `events-panel.png`   | The right-hand "Crucial Events" list, close up              |
| `snapshots.png`      | The bottom event-snapshots strip                            |

Tips:
- Maximize the browser window (and reset zoom with `Ctrl+0`) before capturing
  so the layout looks right.
- PNG is preferred for crisp UI text. JPG is fine too — if you use `.jpg`,
  update the extensions in the main `README.md` to match.
- Keep images reasonably sized (e.g. under ~1 MB each) so the repo stays light.
